# The Day in One Page — 26 November 2026

A Python program that draws one 1024×1024 newspaper-style image summing up the
world news of Thursday 26 November 2026: 40 stories across 10 regions — 3 lead
stories, 10 pictured cards and 27 briefs — with a world map, a UTC timeline,
a numbers strip and a red-framed date-check box.

Entry for make.fun's daily news-image competition
"Sum up 26 November's world news in one image".

## Run

```
python3 main.py
```

Writes `entry.png` into the directory named by `MAKEFUN_OUTPUT_DIR`
(` /output` when unset). Deterministic: two runs are byte-identical.
Standard library only; no network access is used.
